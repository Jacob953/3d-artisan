# 3D Artisan

跟随 Lydia Sloan Cline 的《Fusion 360 for Makers》学习三维建模，让设计逐步走向可制作的模型。

本仓库使用 Shapeshifter reading 模板 0.5.0。默认用中文讲解，保留英文工具名方便查找；这是初始学习安排，可随目标和实际基础调整。

学习采用主动带学：在对话中直接讲解、举例，并根据反馈安排下一步操作。原书由 agent 按需定位，你无需先自行读完再提问。

## 从这里开始

- [第一段阅读指引](books/fusion-360-for-makers/START-HERE.md)：从前言了解 Fusion 与建模方式。
- [全书学习路线](books/fusion-360-for-makers/LEARNING-PLAN.md)：基础、项目与制造延伸。
- [当前学习状态](books/fusion-360-for-makers/state.yaml)：记录阅读断点，不凭准备工作推断已读或掌握。

在这个仓库的 Codex 聊天中说“继续学习”“解释这一节”或“查看进度”即可；有明确练习意愿时再做建模练习。尚未确认你的基础、Fusion 安装情况和制作设备，不预先假定。

## 书籍与资料

- 书名：Fusion 360 for Makers: Design Your Own Digital Models for 3D Printing and CNC Fabrication
- 作者：Lydia Sloan Cline
- 出版日期：2018-05-01（EPUB 元数据）
- 当前书籍：`fusion-360-for-makers`
- [来源清单](books/fusion-360-for-makers/source/manifest.yaml)保存文件指纹；[目录索引](books/fusion-360-for-makers/source/catalog.yaml)用于定位。

原始 EPUB 保存在本机 `books/fusion-360-for-makers/source/local/`，原书和可还原的正文分片不进入 Git。另一台设备需提供相同 EPUB，并按来源指纹重新准备本地索引；仓库保留阅读位置和学习记录。此处的文件相对路径以仓库根目录为准。

本书描述的是出版时的软件。涉及安装、授权、系统要求、菜单位置及扩展工具时，按当时的学习任务核对 Autodesk 当前官方资料，并标明差异。
