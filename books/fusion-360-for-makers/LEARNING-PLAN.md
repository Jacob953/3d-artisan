# 《Fusion 360 for Makers》学习路线

这是一份依据书籍目录制定的初始安排，不是完成记录。先按零基础可进入的阅读起点提供材料；实际节奏由你的目标、已读范围和操作反馈决定，不设固定周数或强制测验。

## 推荐顺序

| 阶段 | 原书章节 | 关注点与后续动手方向 |
| --- | --- | --- |
| 阅读入口 | Preface | Fusion 的用途、三类建模方式；按需回看术语表 |
| 操作基础 | 1 — The Fusion 360 Interface | 认识界面与视图导航；对照实际界面定位工具 |
| 草图基础 | 2 — Sketching | 工作平面、单位、约束、尺寸与草图编辑 |
| 创建模型 | 3 — Making Models: The Create Menu | 实体与组件、建模流程及创建工具 |
| 修改模型 | 4 — Editing Models: The Modify Menu | 修改工具、参数与依赖关系 |
| 制作准备 | 5 — Best Practices and Netfabb for Fusion | 检查可制造性；扩展工具到此时再核对可用性 |
| 首个项目 | 6 — Emoji Wall Art | 将轮廓变成实体，并观察时间线修改 |
| 形体练习 | 7 — Two Chairs and a Vase | 按书中项目继续练习不同形体 |
| 尺寸与阵列 | 8 — Fidget Spinner | 结合尺寸、偏移、阵列及边缘处理 |
| 机械结构 | 9 — Gears | 齿轮与行星齿轮项目；外部工具按需核对 |
| 部件与装配 | 10 — Car Phone Mount Assembly | 多部件建模、单独导出与装配 |
| 图纸表达 | 11 — 2D Layout | 视图、尺寸、标注与图纸导出 |
| 延伸主题 | 12 — Slicer for Fusion | 理解原书的片材构造流程；学习到此处时核对工具现状 |
| 制造延伸 | 13 — The CAM Workspace | 理解刀路、设置与模拟；结合实际制造目标学习 |

建议先读前四章并穿插你主动选择的小练习，再进入项目。第 5 章在准备制造时回看；第 12、13 章根据兴趣和设备决定深度。这是学习安排，不表示这些章节已经读过。

## 每次学习如何推进

先提供一段可定位的完整内容，说明为什么值得读，必要时用中文解释背景。你可以连续阅读、直接提问或要求示范。你报告读完后再记录已读范围；想练习时，根据实际操作、模型或明确的自述给出反馈。文字解释与真实建模表现分别记录，不自动判定掌握。

用户已明确选择主动带学：每次由 agent 在对话里直接讲解一个小概念，配合例子，再根据反馈推进；上述原书定位供补充阅读，不要求用户先自学后提问。

模型项目完成后保留设计文件，后续章节可能复用。练习文件的保存位置与是否同步，在第一次生成作品时按实际文件类型确定。
