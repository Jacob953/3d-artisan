# 阅读、示范与修正

按完整思想划分当前语义单元，用 read 获取原文；索引可以预先建立，内容理解与知识模型随学习增量形成。原文位置必须包含 source_id、文件/锚点与版本指纹。不要以整本书或固定字数替代合理单元。

连续阅读后可先让用户自由回忆、解释或预测，再对照原文诊断。不要不停打断，也不要在首次独立尝试前主动展示答案。用户需要直接解释时提供，并记录帮助程度；新手可用示范，随能力增长减少支持，不把苏格拉底式提问当硬流程。

只检索当前任务需要的前置知识，必要时补查相邻原文与反例。知识条目表达机制、适用线索、方法、边界和来源，按需要组织，不强制填满。原书主张、模型推断、实践发现分别标明。学习者没掌握不妨碍记录有依据的知识；记录知识也不构成掌握证据。

感官与动作能力需要实际观察或明确注明的用户报告，文字回答只支持相应范围的判断。有效回答、提示、修正及时保存，见 data.md。

## 首次阅读与按需分流

“带我学习这本书”默认不是测验请求。没有基础证据时，先看书的目录和当前阅读位置，选一个适合入门的完整思想；不要因某个术语或练习容易获取，就把它当成第一课。不要求先填目标表或创建 capability/task。

第一次有效回复应包含：这一小段为什么值得读、具体读什么（可用材料或精确阅读入口）、必要的背景。允许附一个不要求知识基础的观察方向，不预先泄露随后要检验的结论。提供材料后给用户连续阅读的空间；不要同轮默认发出闭卷考题。路径/片段 ID 本身不是用户可用的阅读入口。无法提供原文时如实说明并给出可靠的定位或明确标为讲解的内容，不能假称用户已读。

用户确认读完、主动复述或提出具体困惑后，再决定解释、示范、回忆或应用。没有读完就先处理阅读困难；请求直接讲解就讲解。无需逐条执行固定教学流程，不设统一页数、问题数或强制阅读确认问卷。用户明确要求预测或入门诊断时可以阅读前提问，注明它是探索而非掌握检验。

区分 agent 已检索、材料已提供、用户报告已读、得到帮助和独立表现。只有真实用户报告支持 read_ranges；阅读完成不提升 mastery。答案已在同轮或相关讲解中出现，后续表现按有帮助处理；改变措辞不恢复独立性。独立检验需要没有泄露答案的新任务，保留此前帮助记录。
