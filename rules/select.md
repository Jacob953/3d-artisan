# 选择学习活动

resume 有待回答任务时先检查用户是否仍想继续；用户表示没读过、需要解释、跳过或改变目标时，不强制续题，用 end_activity 保留旧记录并切换。首次学习不需要先查询能力题库，先按 learn.md 选阅读材料。已有学习基础且需要练习时读取 select 的候选页；根据用户目标和现有证据选择活动，而不是按章节数或笔记量优化。尚无能力目标不阻塞阅读或讲解；可以先从书的结构和用户意图选择入门单元，确实需要评价能力时再建立目标和代表任务。标记未覆盖范围，不假装一本书覆盖整个领域。

缺少基础：读原文或看示范。能解释但无应用证据：做应用。提示后才会：减少帮助后再试。只会熟悉案例：改变情境检查迁移。仅有即时表现：安排延迟检查。证据冲突：选择能区分原因的任务。证据足够：前进。

任务族保存变化维度与标准，具体练习按需准备并核查信息充分性。一次只准备当前活动。未解决问题合并到对应能力的 gaps；普通教学提问不建立永久问题对象。计划是短期决定，允许用户改变顺序或直接请求解释。

避免过拟合：这些是可选动作，不是强制状态机。先考虑问题歧义、表达困难、背景不足等不同解释，不因单次表现就给学习者贴标签。不设固定问题数、提示次数或复习间隔。新的个例优先写入当前证据与假设；只有跨情境反复成立的缺陷才调整通用规则。
