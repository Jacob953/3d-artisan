# 评价与复查

用 evaluate 加载本次问题、标准快照、回答、已给帮助、相关能力状态和原文依据。资料不足先补查，不能拿知识条目 ID 或个人印象代替证据。

分别记录可观察表现与原因假设，注明 agent/user/external 的评价来源。独立完成、提示下完成、陌生情境应用、延迟保持是不同证据维度；未检查就写 untested / insufficient_evidence，不换算成虚假的掌握百分比。

评价标准在发题时保存快照。训练中的示范和提示不得算作独立测验成功。迁移用有意义的新情境；延迟检查记录真实时间和条件。解释流畅不证明操作、感官或成品质量达标。

learner 中每项 demonstrated 判断引用 practice 证据。遇到矛盾保留证据，修订有范围的当前判断。评价不会自动写入数据；保存前按 data.md 校验引用和帮助条件。
